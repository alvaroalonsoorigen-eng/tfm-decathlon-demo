En el ordenador, el botón «Demos guiadas» (o la tecla D) abre tres demostraciones separadas, Acción 1, Acción 2 y cuadro de mando, que se pasan con las flechas o con un mando de presentaciones; la tecla C pone la pantalla completa.

No es una web ni una app oficial de Decathlon y no tiene relación con la marca. Personas, saldos, productos y precios son ficticios o ilustrativos; los datos del cuadro de mando son simulados. Las cuentas de prueba están cifradas: sin el correo correspondiente no se puede leer ningún dato.
